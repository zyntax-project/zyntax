println → console.log io

ZynML's println() on the wasm target routes through a _zyntax_console_log wasm-bindgen extern. The default zynml.mjs binding calls console.log, so each line shows up both in DevTools and (because this page intercepts console.log) in the panel below. 

def main(): i64 {
    println("hello from ZynML")
    println_i64(7 * 6)
    println_bool(true)
    return 0
}
expected: three lines — hello from ZynML, 42, true. Status ok.
