chained awaits async

Two consecutive await sleep calls separated by a local binding. Exercises the krio captures-lift transform: the local x defined between awaits must be saved to the state-machine frame across the first yield and reloaded on resume. 

async def main(): i64 {
    await sleep(50)
    let x = 10
    await sleep(50)
    return x * 4
}
expected output: 40 · elapsed ≥ 90 ms (two ~50 ms parks must compound).
