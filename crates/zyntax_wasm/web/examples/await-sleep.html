await sleep async

The minimum cooperative-async program: park on await sleep(100), then return 42. The runtime parks the state machine, the JS-side setTimeout(…, 100) fires, the SM resumes, and the Promise resolves. 

async def main(): i64 {
    await sleep(100)
    return 42
}
expected output: 42 · elapsed ≥ 90 ms (the parking actually yielded; a busy-wait would finish in <5 ms).
