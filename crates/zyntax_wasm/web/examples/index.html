ZynML browser demos

Each page loads the wasm bundle, runs a small ZynML program through call_async, and reports the result + the wall-clock elapsed. The elapsed-time check is the load-bearing bit: a real cooperative yield surfaces as ≥ N ms, while a busy-wait would finish in microseconds.

Cooperative-async demos

  • await sleep

    Minimum cooperative-async program. Parks on a single await sleep(100), returns 42.

  • chained awaits

    Two consecutive awaits with a local binding between them. Exercises captures-lift across multiple yields.

  • arithmetic, then await

    Synchronous setup, then a single await; verifies live locals survive the park.

I/O demos

  • println → console.log

    println("…"), println_i64, println_bool in ZynML — all routed through wasm-bindgen to console.log. Output shows up both in DevTools and inline on the page.

Build & serve

Each demo loads ../pkg-web/zyntax_wasm.js + its sibling .wasm. Build the bundle first, then serve crates/zyntax_wasm/web/ over HTTP (the file:// scheme blocks ES-module imports of wasm glue). 

cd crates/zyntax_wasm
./build.sh web

# Recommended: Node server with cross-origin-isolation headers
# (COOP / COEP / CORP — unlocks SharedArrayBuffer and the advanced
# wasm feature set):
node web/serve.js 8000
# then visit http://localhost:8000/web/examples/index.html

# Alternative if you only need basic wasm: any static server works.
#   python3 -m http.server 8000
# (no COOP/COEP — fine for the current demos but limits future
# features.)
