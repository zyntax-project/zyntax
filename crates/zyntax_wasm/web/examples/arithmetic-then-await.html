arithmetic then await async

Synchronous setup followed by a single await. Verifies that the captures-lift transform stages live locals across the yield boundary correctly — the result of a * b must survive the park. 

async def main(): i64 {
    let a = 7
    let b = 6
    let c = a * b
    await sleep(80)
    return c
}
