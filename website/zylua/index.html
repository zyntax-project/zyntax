zylua: Lua on Zyntax

zylua is a Lua 5.4 runtime. It compiles Lua source to the typed AST of Zyntax. It finds the types of values. When it knows a type, it keeps the value in typed form. Each function starts in the interpreter. zylua compiles a frequently used function to machine code with Cranelift, and then with LLVM.

This page shows the benchmark results from CI. The CI workflow runs each benchmark on zylua, LuaJIT and PUC Lua 5.4. All three must print the same result as PUC Lua. A row that does not agree is not on this page. The source of each benchmark is in crates/zyntax_lua/benchmarks.
