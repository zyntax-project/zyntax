About

This page loads zyntax_wasm built with wasm-pack build --target web and runs a ZynML source in-browser. The wasm module ships the full grammar, bytecode interpreter, and the wasm-emitting Tier-1 JIT — hot functions get JIT-compiled to fresh wasm modules and re-instantiated transparently.

Isolation status: unknown. Cross-origin isolation is required for SharedArrayBuffer + a future SAB-backed worker-pool runtime. The single-Worker mode in use today does not require it. See docs/wasm-deployment.md for hosting recipes.
